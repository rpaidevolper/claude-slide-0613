## 一、課程概覽

本場工作坊以「Claude」為核心，帶領學員從**會用 AI** 走到**會指揮 AI**，並親手體驗讓 AI 替自己產出真實作品的完整流程。

| 項目     | 內容                                                       |
| -------- | ---------------------------------------------------------- |
| 對象     | 嘉義女中師生（含 AI 電資班、醫藥科技班同學）               |
| 核心工具 | Claude Chat（對話）／ Claude Cowork（共工）／ Claude Code（程式） |
| 三大重點 | Prompt 的真相、AI 基礎知識、把 AI 變成你的數位夥伴         |
| 核心成果 | **一份由學員共創完成的「認識嘉女」介紹網站**               |

> **一句話總結這堂課：** AI 放大的是你腦袋裡的東西 ── 學科知識、表達能力、生活觀察，全部都會被 AI 加倍放大。

## 二、課程亮點回顧

以下六個單元，是這場 6 小時工作坊走過的完整脈絡。每一段都附上「你應該帶走的一句話」，方便日後快速喚起記憶。

### 單元 01｜學生必知的 AI 工具
我們一起盤點了當前主流的 AI 工具光譜（ChatGPT / Claude / Gemini / Perplexity / NotebookLM…），並建立屬於自己的**工具選擇判斷力**：不是哪個最紅就用哪個，而是「哪個最適合此刻的任務」。

> **Key Take：** 工具會換，判斷力不會。先學會分類，再學會選擇。

### 單元 02｜Prompt 的真相
這堂課戳破了一個迷思 ── **難的從來不是「怎麼寫 Prompt」，而是「你到底想清楚了沒」**。我們用好壞範例對照，練習把模糊的需求拆成具體可執行的指令。

> **Key Take：** 寫不好 Prompt，不是因為你不會寫，而是因為你還沒想清楚。

### 單元 03｜必須掌握的 AI 基礎知識
這段我們認識了三個關鍵詞：**Skill（技能）／ Token（成本單位）／ MCP（連接器）**。看懂這些詞，你就從「使用者」升級成「指揮者」，知道如何幫 AI 安裝能力、如何控制花費。

> **Key Take：** 不需要懂寫程式，但要懂 AI 是怎麼計費、怎麼擴充能力的。

### 單元 04｜用 Claude Chat 解決真實困擾
小組接力練習：**策略 → 文件 → 作品**。我們把日常生活中的真實困擾（讀書計畫、報告大綱、社團企劃）丟給 Claude，一步步把模糊想法變成可交付的成果。

> **Key Take：** Claude 不是答案產生器，而是思考加速器。

### 單元 05｜讓 Claude 代替你操作電腦（Cowork）
這段最震撼 ── **AI 不只會講，還會動手**。我們示範了 Claude 直接讀取檔案、修改 Excel、整理資料的場景，讓學員看見 AI 從「對話夥伴」進化為「實習助理」的關鍵跳躍。

> **Key Take：** 重複性高、規則明確的事，從今天起交給 Claude。

### 單元 06｜未來指南：學科知識才是真本錢
最後我們回到一個重要的提醒：**AI 越強，學科知識越值錢**。因為 AI 放大的是你腦袋裡既有的東西 ── 你懂生物，AI 就能幫你寫出更深的生物報告；你懂歷史，AI 就能幫你做出更動人的歷史影片。

> **Key Take：** 不要因為有了 AI 就放掉課本，而是要因為有了 AI 而學得更深。

## 三、課堂共創成果 ─「認識嘉女」專題

這場工作坊最特別的環節，是我們**一起共創了一份介紹嘉女的作品**。這不只是一個練習，而是把整堂課所學的 Prompt 技巧、Claude Code 模式、共創思維，全部濃縮成一個可以帶走的真實作品。

### 3.1 共創流程（我們在課堂上實際走過的三步）

```
Step 1  口語經驗收集
       ↓ 全班腦力激盪：嘉女有什麼讓你覺得特別的地方？
Step 2  結構化整理
       ↓ 講師協助梳理成「四大面向 + 核心論點 + 支撐內容」的 Prompt 大綱
Step 3  Claude Code 產出
       ↓ 把 Prompt 餵給 Claude Code，產出一份可上線的學校介紹網站
```

### 3.2 共創產出物

1. **一份完整的簡報大綱**（即本文件附錄 A）── 涵蓋環境友善、運動風氣、創新精神、社會接軌四大面向
2. **一份介紹嘉女的網站**（由 Claude Code 模式直接從附錄 A 的 Prompt 產出）

### 3.3 這次共創真正教會我們的事

> **從口語經驗，到結構化 Prompt，到 AI 產出真實作品 ── 這條路徑，就是 AI 時代每個人都應該擁有的「作品生產力」。**

換句話說：以後你想做任何作品（報告、影片腳本、活動企劃、社團網站），都可以走這條路 ── 先把腦袋裡的東西說出來，再幫它找一個結構，最後讓 AI 幫你長出來。

### 3.4 如何用這份 Prompt 自己重現網站

回家後，你也可以自己跑一次完整流程：

1. **安裝 Claude Code** ── 參考官方文件 [docs.claude.com/claude-code](https://docs.claude.com/claude-code)
2. **建立專案資料夾**，在資料夾中打開終端機輸入 `claude` 啟動
3. **貼上附錄 A 的 Prompt 全文**，並補上一句指令：

   > 「請幫我用 React + Tailwind CSS 產出一個單頁網站，把上述大綱轉成視覺豐富、適合給國中生與家長瀏覽的學校介紹網站。」

4. **預覽 → 迭代 → 部署**（可結合 GitHub Pages / Vercel 直接發布到網路上）

### 3.5 進階玩法（給想再走遠一點的你）

- **換主題：** 把同樣的 Prompt 結構，套用在你的社團、班級、家鄉
- **換工具：** 把附錄 A 丟進 NotebookLM，變成一個「可以問答的嘉女介紹助理」
- **換受眾：** 請 Claude 把同一份大綱改寫成「給國中生看的招生版」、「給家長看的家長日版」、「給校友看的回母校版」

## 四、補充學習資源

以下三個資源，是課堂上來不及深入、但**強烈建議課後一定要去逛逛**的延伸學習。

### 4.1 NotebookLM｜你的專屬 AI 研究助理

- **連結：** [notebooklm.google.com/notebook/creating](https://notebooklm.google.com/notebook/creating)
- **它是什麼：** Google 推出的 AI 筆記本，可以把上課講義、論文 PDF、影片逐字稿全部丟進去，生成摘要、心智圖、甚至**自動產出兩個 AI 主持人對談的 Podcast**。
- **對應課程：** 單元 01（AI 工具選擇）
- **建議練習：** 把這份結案文件 + 課程簡報，整包丟進 NotebookLM，請它幫你**生成 5 題自我檢核題**，測測自己學到多少。

### 4.2 SkillsMP｜Claude Skill 市集

- **連結：** [skillsmp.com](https://skillsmp.com/)
- **它是什麼：** 一個 Claude Skill 的市集，讓你像下載 App 一樣，把別人寫好的「AI 技能」裝到自己的 Claude 上。
- **對應課程：** 單元 03（Skill 概念）
- **建議練習：** 挑一個你看了眼睛會發亮的 Skill 安裝到自己的 Claude，當作**課後第一個自動化體驗**。沒裝過，你不會真的懂 Skill 是什麼。

### 4.3 實戰範例｜讓 Claude 修改 Excel 資料

- **連結：** [Claude × Excel 實戰範例](https://app.notion.com/p/Claude-Excel-37f69c40ccdb8135a91adfd082bf7e56?source=copy_link)
- **它是什麼：** 一份完整的步驟示範，教你怎麼讓 Claude 在 Cowork 模式下直接讀取、修改、整理 Excel 資料。
- **對應課程：** 單元 05（Cowork 模式）
- **建議練習：** 拿一份自己的考試成績、社團名單、班費收支表，照範例請 Claude 幫你整理一次。第一次成功，你就回不去手動了。
